# Proposed judging worksheet
Verify official weights before use. Planning weights: Napster API 30, technical execution 25, creativity 25, presentation 20. Judge scores each 0–5 with evidence, weighted total = sum(weight × score / 5). Report missing evidence separately, not as a verified capability. API: embodied identity and meaningful interaction; technical: handoff, reproducibility, reliability; creativity: self-modeling versus generic roleplay; presentation: understandable three-minute journey. Score at stage 6, 9 and release; prioritize fixes by expected impact and effort. This is an internal estimate, not official judging.
